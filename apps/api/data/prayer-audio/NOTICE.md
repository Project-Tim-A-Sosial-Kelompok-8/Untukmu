# Rekaman sumber untuk kurasi

Berkas berikut disertakan tanpa perubahan. Metadata, checksum SHA-256, ukuran,
durasi, bahasa, dan keterkaitan katalog dicatat dalam `../prayer-audio-candidates.json`.
Berkas ini merupakan bahan peninjauan; keberadaannya tidak menyetujui kurasi.

Untuk rekaman Metta Forest Monastery, segala penjualan dianggap komersial oleh
penyedia, termasuk penjualan oleh organisasi nonprofit. Gunakan atribusi di
manifest saat membagikannya. Rekaman tersebut tidak diubah atau dipotong.

Penelusuran sumber dilakukan pada 2 Oktober 2026. Skrip
`scripts/fetch-prayer-candidates.py` dapat mengambil kembali berkas dan akan
menolak checksum yang berubah; perubahan sumber perlu diperiksa sebelum
manifest diperbarui.
