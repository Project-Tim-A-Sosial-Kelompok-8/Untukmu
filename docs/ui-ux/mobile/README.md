# UI/UX mobile

Buka [galeri lengkap](index.html) untuk melihat **71 layar/keadaan** dengan **124 gambar** dari web yang sebenarnya. Viewport: 390 × 844 px.

Panel panjang direkam per bagian dengan ukuran viewport asli. Data adalah contoh pada layanan uji; tidak memuat akun pengguna produksi. Nama layar, cara menuju, tindakan, dan hasilnya tercatat pada [manifest](manifest.json).
